Why this is useful

Portable artifacts

Bundle retrieval memory and configuration into one object you can move across machines and environments.

Provider-agnostic

Swap embedding and LLM providers without redesigning your entire RAG stack.

Fast startup

Load prebuilt index + metadata quickly, so apps can answer with context immediately.
