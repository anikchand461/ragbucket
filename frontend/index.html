GitHub PyPI

Why RAGBucket?

Modern retrieval systems should be portable, modular, lightweight, and provider-agnostic. RAGBucket gives you a complete executable RAG pipeline packed into a single artifact.

.rag Artifacts

Store vectors, chunks, manifest configuration, and retrieval metadata inside one portable executable file.

Multi-Provider AI

Use Groq, OpenAI, Gemini, Anthropic, Cohere, local embeddings, and more using one clean abstraction.

Lightweight Core

Heavy dependencies are optional. Local embedding models download only when required.

Portable Runtime

Build retrieval memory once and deploy it across different environments instantly.

System Architecture

RAGBucket separates retrieval, embeddings, indexing, packaging, and generation into independent modular layers.

Quickstart

Build your first portable retrieval artifact in minutes.

from ragbucket import RagBuilder, RagConfig config = RagConfig( embedding_provider="cohere", embedding_model="embed-english-v3.0" ) builder = RagBuilder(config=config) builder.build( doc_path="docs/", op_path="artifacts/demo.rag" )
