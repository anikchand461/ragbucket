What is this actually doing?

This pipeline transforms raw files into searchable memory, then retrieves the most relevant chunks for LLM generation.

Build phase

Input docs are chunked and embedded, then packed with index + manifest.

Runtime phase

User query is embedded, nearest chunks are fetched, then answer is generated with grounded context.

Separate build/runtime gives portability and predictable behavior.
